# Engineering research

Answer the engineering question from **primary sources**: official documentation, specifications, source code, first-party APIs, release notes, or original papers. Trace each material claim to the source that owns it; use secondary sources only to discover primary ones.

Define the decision and freshness requirement before searching. Prefer repository-local truth first, then current external sources. Separate sourced fact from inference, compare version/date/applicability, and call out unresolved contradictions. Cite the direct supporting source beside each conclusion.

Keep the deliverable decision-shaped: question, findings, recommendation, constraints, and unknowns. Write a Markdown artifact only when the task requests one or the repository already requires research notes; otherwise return the compact cited result. Never silently broaden research into implementation.
